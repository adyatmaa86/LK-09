# Judul Project Anda

## Cara Instalasi
1. Clone repository ini: `git clone <url-repo>`
2. Masuk ke folder project: `cd <nama-folder>`
3. Install dependency PHP: `composer install`
4. Install dependency JS: `npm install`
5. Copy file .env: `cp .env.example .env` (atau manual copy di Windows)
6. Generate App Key: `php artisan key:generate`
7. Sesuaikan setting database di file `.env`
8. Jalankan migrasi: `php artisan migrate`
9. Jalankan server: `php artisan serve`
